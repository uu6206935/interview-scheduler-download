# 面接日程 自動作成ツール（配布用）

学生回答・職場回答・人事回答の Excel から、面接日程表（`調整用` シート形式）を自動で作成するローカル用ツールです。

## ダウンロード

**[interview-scheduler-v2.zip をダウンロード](https://github.com/uu6206935/interview-scheduler-download/releases/latest/download/interview-scheduler-v2.zip)**

zip は**パスワード付き**です。パスワードは配布者からお知らせします。

## 使い方

1. zip を展開します（パスワードが必要です）。
2. 展開した `interview-scheduler` フォルダの `README.md` を読み、`start.bat` をダブルクリックして起動します。

`input/` フォルダには動作確認用の架空データが入っています。実際に使うときは差し替えてください。
